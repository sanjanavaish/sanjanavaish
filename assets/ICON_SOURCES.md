# Inline brand icon sources

All marks are vector paths embedded directly in the SVG source; there are no runtime icon fetches.

- **Simple Icons**: React, JavaScript, HTML5, CSS3, Bootstrap, Git, MongoDB, MySQL, Python, and GitHub paths were extracted from the locally installed Simple Icons font package (TeX Live `simpleicons` v14.9.0, released 2025-03-07). Project: https://simpleicons.org/ . Simple Icons assets are distributed under CC0 1.0; brand/trademark rights remain with their owners.
- **LinkedIn**: not present in the local Simple Icons glyph set used for this build; its brand path is from Font Awesome Free Brands v6.7.2 (`faLinkedin`), licensed CC BY 4.0. Source: https://github.com/FortAwesome/Font-Awesome . Attribution: Font Awesome by Dave Gandy.
- **Email envelope**: simple, generic inline vector, not a third-party logo.

Icons are decorative in SVG images. The clickable social links are standard Markdown anchors under `assets/connect.svg` in `README.md`, since GitHub does not expose SVG-internal links as normal README links.
